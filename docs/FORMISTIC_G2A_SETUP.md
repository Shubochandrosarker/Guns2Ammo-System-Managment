# Formistic × Guns 2 Ammo — Owner Setup Guide

Step-by-step for switching the Guns 2 Ammo site's contact system from the old
**WPistic Contact Form** plugin to **Formistic** (v2.0.5+). Follow the steps in
order — the sequence matters (import before deactivating the old plugin).

The theme is already wired: every theme form (reservation, transfer request,
contact, newsletter) automatically stores into Formistic when it's active, and
falls back to the old plugin if it isn't. Guests can submit without logging in;
nothing changes on the public site.

---

## 1. Activate Formistic

**Plugins → Installed Plugins → Formistic → Activate.**

Activation creates the `wpistic_formistic_*` database tables and seeds the
Guns 2 Ammo AI knowledge defaults (fill-only — it never overwrites anything you
have already typed in).

Leave the old **WPistic Contact Form** plugin active for now — you still need
its data. Both plugins can coexist temporarily (separate tables, options, and
classes), but don't run both long-term: they both register the
`[wpistic_contact_form]` shortcode, so pages using that shortcode can behave
unpredictably while both are active (see step 9).

## 2. Import the old plugin's data

**Formistic → Settings → General tab → Tools → "Import from Wpistic Contact
Form".**

- Copies submissions, replies, attachments (rows *and* files), internal notes,
  impressions, and newsletter subscribers into the Formistic tables.
- Idempotent — already-imported rows are skipped, so it's safe to click again
  (e.g. after a timeout on a huge inbox). Runs in 500-row batches.
- The old tables are left untouched (your rollback copy).
- A notice reports exactly how many rows of each type were imported.
- The button only appears while the old plugin's tables exist.

Note: the old plugin's AI metadata table (spam scores / draft replies) is not
imported — those are regenerated by Formistic's own AI module as new mail
arrives.

## 3. Enable the addons you need

**Formistic → Addons.** Turn ON:

- **Newsletter** — the footer "GET RANGE UPDATES" list. Subscribers live in
  their own table (`wpistic_formistic_subscribers`), fully separate from the
  contact inbox. The addon is OFF by default; signups are still stored while
  it's off, but you need it ON to see/export the list.
- **Auto Responder** — instant "we got your message" acknowledgement email.
- **AI Automation** — smart reply drafts, tags, spam scoring, and the keyword
  auto-reply rules.

`Form Captures`, `Spam Protection`, and `Reply Templates` are ON by default —
leave them on.

## 4. Configure the AI provider (OpenRouter)

**Formistic → Settings → AI & Automation tab:**

1. **Provider:** `OpenRouter (Free model routes)`.
2. **API Endpoint:** leave blank — it automatically defaults to
   `https://openrouter.ai/api/v1/chat/completions` for OpenRouter.
3. **API Key:** paste your key from https://openrouter.ai/keys.
4. **Model:** e.g. `meta-llama/llama-3.1-8b-instruct:free` (any OpenRouter
   model ID works; `:free` routes cost nothing).
5. Tick **Enable Smart Reply Drafts** (drafts + tags appear in the inbox).
   Only tick **Enable Auto Reply Send** once you're happy with the drafts —
   that one emails customers automatically.

If the provider call ever fails, Formistic silently falls back to the local
rule-based reply so customers still get an answer; the failure reason is
recorded with the submission's AI metadata (provider field) for debugging.

## 5. Seed the Guns 2 Ammo defaults

**Formistic → Settings → AI & Automation tab → "Seed Guns 2 Ammo defaults"**
(also available under General → Tools).

Fills these fields **only when they're empty** — your edits are never
overwritten:

- **FAQs** and **Knowledge Base** — verified business facts (address, phone,
  hours, 6 lanes, membership tiers + pricing, guest pricing, CCW course
  pricing, FFL/NFA fees, instructor bios, online booking flow). This is what
  the AI reads before drafting replies.
- **Easy Automation Rules** — warm, professional keyword templates for the
  common intents: CCW/class/course, FFL/transfer, membership, lane
  booking/reservation, hours/location, NFA/suppressor.
- **Auto Reply Subject.**

Review the seeded text afterwards and tweak wording/prices as things change —
once edited, re-seeding won't touch your version.

## 6. Trusted proxies (Cloudflare)

The site sits behind Cloudflare, so PHP sees Cloudflare's IP as the visitor.
For rate-limiting and IP blocklists to work per *visitor* (not per Cloudflare
edge node), Formistic needs Cloudflare's IP ranges in its trusted-proxy list.

Since v2.0.6 this is filled in **automatically** — the "Seed Guns 2 Ammo
defaults" step (step 5) also fill-only seeds **Formistic → Settings → Spam
tab → Trusted proxies** with Cloudflare's published ranges, so this normally
needs no manual action. Skipping it is exactly what causes the classic
symptom "the form redirects to a success page but nothing shows up in the
inbox" — every visitor collapses onto Cloudflare's shared edge IP, and the
default 3-submissions-per-hour limit blocks almost everyone after the first
few.

Verify it's populated: **Formistic → Settings → Spam tab → Trusted proxy
list** should already show a long comma-separated list. If it's empty (e.g.
you installed before v2.0.6 and never clicked "Seed Guns 2 Ammo defaults"),
paste Cloudflare's ranges from https://www.cloudflare.com/ips/ yourself, or
click that seed button again. Leave the field empty only if the site is ever
moved off Cloudflare.

## 7. Privacy: leave the wp_mail catch-all OFF

**Formistic → Settings → Captures tab → "Any form that sends email
(catch-all)"** must stay **OFF** (it is off by default). It records a copy of
*every* email WordPress sends — including password resets and customer order
emails — which is a privacy liability. All Guns 2 Ammo forms are captured
directly by the theme bridge; the catch-all is not needed.

## 8. Verify before switching off the old plugin

1. **Guest contact form:** log out (or use a private window), submit the
   contact/reservation form. Confirm it lands in **Formistic → Inbox**. Guests
   must be able to submit without logging in — the theme handles this with a
   cache-resilient front-end POST, no nonce wall.
2. **Newsletter separation:** subscribe via the footer form; confirm the email
   appears under **Formistic → Newsletter** (NOT in the Inbox) and that the
   contact submission from step 1 did not create a subscriber.
3. **Imported history:** spot-check a few old submissions and their replies in
   the Formistic inbox, and old subscribers in Formistic → Newsletter.
4. **Dashboard API (optional):** the operations dashboard reads
   `GET /wp-json/formistic/v1/submissions`, `/submissions/{id}`,
   `/subscribers`, and `/stats` using a WordPress **Application Password** for
   an administrator account (Users → Profile → Application Passwords). A quick
   check: `curl -u 'admin:xxxx xxxx xxxx xxxx' https://SITE/wp-json/formistic/v1/stats`.

## 9. Deactivate WPistic Contact Form

Once everything above checks out: **Plugins → WPistic Contact Form →
Deactivate.**

Why this must happen: both plugins register the same `[wpistic_contact_form]`
shortcode, and both listen to the same theme form hooks — running both
long-term risks shortcode collisions. (The theme bridge itself is safe: it
prefers Formistic and only stores each submission once.)

Deactivating does **not** delete the old tables — they stay as a backup. Only
delete the plugin (which may drop its data) after you're fully confident in
the migration.

## Notes & tuning

- **Rate limit:** by default a single IP can make **3 submissions per hour**
  (3 per 3600-second window). Genuine customers occasionally hit this (e.g. a
  transfer request plus a contact question plus a class booking). Change it at
  **Formistic → Settings → Spam tab → Rate limit (per IP)** — "Max
  submissions" and "Window (seconds)". Keep it enabled; it's the main bot
  brake. Make sure step 6 (trusted proxies) is done first, otherwise the limit
  applies to Cloudflare's IPs and can throttle *all* visitors at once.
- **Duplicate protection:** identical submissions from the same IP within 60
  seconds are merged into one (double-click safe). Window is filterable via
  `wpistic_formistic_dedupe_seconds`.
- **Admin notification email:** set the recipient under Settings → General
  (defaults to the site admin email). The theme already emails
  `sales@guns2ammo.com` directly from its own handlers, so Formistic's
  duplicate notification is suppressed for theme forms.
- **Newsletter throttle:** the subscribe endpoint has its own 60-second per-IP
  throttle, independent of the contact rate limit.
